# Java OOP Project 

This repository showcases a set of Object-Oriented Programming (OOP) projects implemented in Java. Each project demonstrates core OOP concepts such as abstraction, inheritance, encapsulation, and polymorphism, applied to real-world scenarios.

## Projects Included

### 1. Nursery School Management System
A simulation of a nursery school that manages different class levels (`BabyClass`, `MiddleClass`, `TopClass`), teacher assignments, student enrollment, activity tracking, and class reporting.  
This project uses abstract classes, inheritance, and validation logic to enforce age limits, teacher qualifications, and class capacity.

### 2. Mission Management System
This system is designed to manage missions for an organization. It tracks missions assigned to agents, validates mission statuses, manages deadlines, and generates mission reports.  
It focuses on the interaction between classes like `Agent`, `Mission`, and `MissionManager`, showing strong encapsulation and class coordination.

### 3. Land Management System
A basic land registry system that manages plots, landowners, and property transfers. It includes features like registering land, verifying ownership, and generating land-related reports.  
This project highlights the use of interfaces, data encapsulation, and role-based validation.
